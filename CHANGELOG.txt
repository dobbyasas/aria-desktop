ARIA FOR MAC - VERSION HISTORY
==============================

Version 1.14.2
Created: 2026-09-01

Changed:
- Artist artwork now fills a wide background hero and loads a high-resolution YouTube Music header image.

Fixed:
- The artist-page back button now directly restores the originating screen and also supports Escape.

Version 1.14.1
Created: 2026-09-01

Changed:
- Artist pages now open as full in-app destinations instead of modal sheets.
- Artist artwork is larger and rectangular, with downloaded and downloadable albums shown before songs.
- Artist data is consolidated and cached for faster repeat visits, with delayed skeletons for slower loads.
- Clickable artist names now highlight with the accent color on pointer hover.

Version 1.14.0
Created: 2026-09-01

Added:
- Added artist pages with YouTube Music portraits, downloaded songs and albums, and additional albums available to download.
- Artist names throughout the library, album views, player, queue, lyrics, and download screens now open their artist page.

Version 1.13.2
Created: 2026-09-01

Fixed:
- Album deletion now uses the server's canonical album ID, avoiding failures caused by stale track lookups.

Version 1.13.1
Created: 2026-09-01

Fixed:
- Advanced the shared release with server cleanup for obsolete placeholder playlist duplicates.

Version 1.13.0
Created: 2026-09-01

Added:
- Added a Songs destination above Albums in the sidebar with every track in the Aria library.

Changed:
- Standalone song and playlist downloads now appear only in Songs and no longer appear between album cards.
- Playlist downloads preserve and repair each song's individual metadata and artwork through the server.

Version 1.12.1
Created: 2026-08-30

Changed:
- Advanced the shared Aria release to include the server fix for reusing uniquely titled songs with legacy playlist metadata.

Version 1.12.0
Created: 2026-08-30

Added:
- Added download results showing how many existing songs were reused and how many new songs were downloaded.

Changed:
- YouTube playlist downloads now create or update a shared Aria playlist containing reused and newly downloaded songs.
- Duplicate checking is enforced by the server for both searched and manually entered song or playlist links.

Version 1.11.0
Created: 2026-08-30

Added:
- Added YouTube Music search and direct downloads for individual songs and full playlists.
- Added confirmed album deletion from the album detail screen.

Changed:
- Standalone songs and playlist downloads remain in the song library without creating partial albums.
- The Albums screen now includes a playable Standalone Songs section for those downloads.
- Download queue labels now cover albums, songs, and playlists.

Version 1.10.0
Created: 2026-08-30

Added:
- Added a Refresh Cover from YouTube action to the metadata editor with progress, success, and error states.
- Added automatic YouTube Music album matching before requesting an album-wide cover replacement from the server.

Changed:
- Artwork refreshes now reload the catalog with cache-busted image URLs so the new cover appears immediately.


Version 1.9.0
